# MoodBloom 🌸

*Your feelings, your stories, your little world.*

A personal mood journal. This first step contains only the **Landing**, **Sign Up** and **Sign In** pages
(UI only — Supabase auth comes next).

## Run it

Requires [Node.js](https://nodejs.org) 18 or newer.

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # production build in /dist
npm run preview  # preview the production build
```

Routes: `/` (landing), `/signup`, `/signin`.

## Stack (all free)
React 18 · Vite · Tailwind CSS 3 · React Router · Google Fonts (Fraunces + Nunito)
